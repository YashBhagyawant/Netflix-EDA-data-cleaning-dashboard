This introductory video provides a basic overview of the dataset and introduces the six stages covered throughout this dashboard development journey. Each stage is explored in detail in the upcoming videos, building a step-by-step understanding of data analysis.

**Dataset overview (Raw Data → Clean Data):**
The workbook contains two sheets:
- **Raw Data** – the original Netflix OTT dataset (titles up to ~500 rows used for the dashboard)
- **Clean Data** – the processed version after data cleaning, ready for analysis

## 🎯 Video 1: Purpose of the Data

<p align="center">
  <img width="675" height="607" alt="post 3" src="https://github.com/user-attachments/assets/5c5dadbc-e2a7-47d4-a3ee-8cc815c47363" />

In this first video, the focus is on understanding the purpose of a dataset by exploring three fundamental questions:

1. **What is the dataset about?** – Understanding the data and its overall context.
2. **What business problem does it solve?** – Identifying the business challenges and objectives behind the data.
3. **Why build a dashboard on it?** – Understanding how data visualization helps transform raw data into meaningful insights and supports better decision-making.

Before building any dashboard, it is important to understand the data, its purpose, and the business value it can deliver.
